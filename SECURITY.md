# Security policy

Security fixes target current `master` and its committed C++/Core source
graph. Report vulnerabilities privately through GitHub's **Report a
vulnerability** form in this repository's Security tab; do not open a public
issue.

Include the exact TypeScript, C++ bridge, and Core revisions, runtime or
browser, reproduction steps, and impact. Never include wallet seeds, spend
keys, wallet files, or production credentials. Key-handling, WebAssembly
integrity, serialization, dependency-chain, and funds-safety reports receive
the highest priority.
